# 元组类型

元组与列表相似，不同之处在于元组中的元素不能修改。

```python
tuple = (233, 6.66, True, 4 + 3j, 'Hello World!')
print(tuple, type(tuple))
```

虽然元组中的元素不可改变，但元组中可以包含列表类型。

```python
tuple = (233, [6.66, 'Hello World!'])
print(tuple)
tuple[1][0] = True
print(tuple)
```

可以通过构造函数的方式来初始化元组。

```python
tuple = tuple({233, 6.66, True, 4 + 3j, 'Hello World!'})
print(tuple)
```

若只创建仅有一个元素的元组，需要在该元素后面添加一个逗号。

```python
tuple = (233,)
print(tuple)
```

也可以对元组进行索引、截取操作。

```python
tuple = (233, 6.66, True, 4 + 3j, 'Hello World!')
print(tuple)
print(tuple[0])
print(tuple[1:3])
print(tuple[2:])
print(tuple[-1:])
print(tuple[:-1])
print(tuple[-1::-1])
```

还可以对元组进行拼接或重复操作。

```python
tuple = (233, 6.66, True, 4 + 3j, 'Hello World!')
print(tuple + (1, 2, 3))
print(tuple * 2)
```

执行下面的代码，统计元组内所有元素个数。

```python
tuple = (233, 6.66, True, 4 + 3j, 'Hello World!')
print(len(tuple))
```

执行下面的代码，统计某个元素在元组中出现的次数。

```python
tuple = (233, 6.66, True, 4 + 3j, 'Hello World!')
print(tuple.count(233))
print(tuple.count('233'))
```

执行下面的代码，从元组中查找指定元素第一个匹配项的索引位置。

```python
tuple = (233, 6.66, True, 4 + 3j, 'Hello World!')
print(tuple.index(6.66))
print(tuple.index('Hello World'))
```

执行下面的代码，获取指定元组排序后的新元组。

```python
tuple = ('Google', 'Facebook', 'TikTok')
print(sorted(tuple))
print(sorted(tuple, reverse=True))
```

执行下面的代码，返回元组中元素的最大值。

```python
tuple = (1, 2, 3, 4, 5)
print(max(tuple))
```

执行下面的代码，返回元组中元素的最小值。

```python
tuple = (1, 2, 3, 4, 5)
print(min(tuple))
```

执行下面的代码，计算元组中元素的总和。

```python
tuple = (1, 2, 3, 4, 5)
print(sum(tuple))
```
