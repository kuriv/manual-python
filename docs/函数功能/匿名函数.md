# 匿名函数

匿名函数通常用于编写简单的、单行的函数。

```python
func1 = lambda: print('Hello World!')
func1()
func2 = lambda x, y: x + y
print(func2(233, 666))
func3 = lambda name, age=18: print(name, age)
func3('Tom', 20)
func3('Jerry')
func4 = lambda x, y: x if x > y else y
print(func4(233, 666))
```

执行下面的代码，在一个匿名函数中定义另一个匿名函数。

```python
func = lambda x: lambda y: lambda z: x + y * z
print(func(1)(2)(3))
```
