# 生成器

生成器可以在迭代过程中逐步产生需要的值，而不是一次性返回所有结果。

```python
list = [i * 5 for i in range(1, 5)]
print(list)
generator = (i * 5 for i in range(1, 5))
print(generator)
print(next(generator))
print(next(generator))
print(next(generator))
print(next(generator))
print(next(generator))
```

也可以使用 `yield` 关键字返回生成器。

```python
def generator():
    yield 1
    yield 2
    yield 3
    yield 4


generator = generator()
print(generator)
print(next(generator))
print(next(generator))
print(next(generator))
print(next(generator))
print(next(generator))
```

执行下面的代码，使用常规循环语句遍历生成器。

```python
def generator(num):
    i = 1
    while i < num:
        yield i
        i += 1


generator = generator(5)
print(generator)
print(next(generator))
print(next(generator))
print(next(generator))
print(next(generator))
print(next(generator))
```
