# 关键字参数

关键字参数是在调用函数时，通过参数名显式指定参数值的传递方式。

```python
def func(**kwargs):
    print(kwargs)

func()
func(name='Tom', age=20)
func(name='Jerry', age=18, gender='female')
```

也可以在调用函数时，把字典拆开作为关键字参数。

```python
def func(name, age):
    print(name, age)

func(**{'name': 'Tom', 'age': 20})
```

执行下面的代码，合并使用位置参数、默认参数、可变参数、关键字参数。

```python
def func(x, y, z=233, *args, **kwargs):
    print(x, y, z, args, kwargs)

func(6.66, True)
func(6.66, True, 2.33)
func(6.66, True, name='Tom', age=20)
func(6.66, True, 2.33, 1, 2, 3, name='Jerry', age=18)
```

还可以执行下面的代码，强制要求必须以关键字形式传递参数。

```python
def func(x, y, z, *, name, age):
    print(x, y, z, name, age)

func(6.66, True, 2.33, name='Tom', age=20)
```
