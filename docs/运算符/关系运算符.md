# 关系运算符

执行下面的代码，进行关系运算。

```python
num1 = 10
num2 = 3
print(num1 == num2)
print(num1 != num2)
print(num1 > num2)
print(num1 >= num2)
print(num1 < num2)
print(num1 <= num2)
```

也可以使用下面的方式进行链式比较。

```python
num1 = 2
num2 = 5
num3 = 8
print(num1 < num2 < num3)
print(num1 < num2 and num2 < num3)
```
