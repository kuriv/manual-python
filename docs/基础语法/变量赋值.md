# 变量赋值

可以在任何时候改变一个变量的类型，而不需要事先声明其类型。

```python
foo = 233
print(foo)
foo = 6.66
print(foo)
foo = 'Hello World!'
print(foo)
```

执行下面的代码，一次为多个变量赋值。

```python
num, str, bool = 233, 'Hello World!', True
print(num, str, bool)
```

也可以执行下面的代码，解包赋值多个变量。

```python
foo, *bar, baz = 1, 2, 3, 4
print(foo, bar, baz)
```

还可以执行下面的代码，交换两个变量的值。

```python
num1, num2 = 233, 666
num1, num2 = num2, num1
print(num1, num2)
```
