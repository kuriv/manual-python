# sys

执行下面的代码，获取系统默认编码格式。

```python
import sys

print(sys.getdefaultencoding())
```

执行下面的代码，获取 Python 解释器的环境变量路径。

```python
import sys

print(sys.path)
```

执行下面的代码，获取操作系统平台名称。

```python
import sys

print(sys.platform)
```

执行下面的代码，获取 Python 解释器的版本信息。

```python
import sys

print(sys.version)
```
