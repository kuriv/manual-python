# 成员运算符

执行下面的代码，判断指定元素是否存在于可包含对象内。

```python
str = 'Hello World!'
print('Hello' in str)
print('Python' not in str)
list = [1, 2, 3, 4, 5]
print(1 in list)
print(6 not in list)
tuple = (1, 2, 3, 4, 5)
print(1 in tuple)
print(6 not in tuple)
set = {1, 2, 3, 4, 5}
print(1 in set)
print(6 not in set)
dict = {'id': 1, 'name': 'Google', 'site': 'www.google.com'}
print('id' in dict)
print('Google' not in dict)
```
