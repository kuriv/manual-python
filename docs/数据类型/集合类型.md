# 集合类型

集合是一种无序、可变的数据类型，用于存储唯一的元素。

```python
set = {'Google', 'Facebook', 'Google', 'TikTok'}
print(set, type(set))
```

也可以通过构造函数的方式来初始化集合。

```python
set = set(['Google', 'Facebook', 'Google', 'TikTok'])
print(set)
```

创建一个空集合需要使用以下的方式。

```python
set = set()
print(set)
```

执行下面的代码，使用 Python 推导式来创建集合。

```python
set = {i for i in range(1, 6)}
print(set)
```

执行下面的代码，统计集合中所有元素的个数。

```python
set = {'Google', 'Facebook', 'Google', 'TikTok'}
print(len(set))
```

执行下面的代码，查找集合中是否存在指定的元素。

```python
set = {'Google', 'Facebook', 'Google', 'TikTok'}
if 'Google' in set:
    print(True)
else:
    print(False)
```

执行下面的代码，对集合进行并集操作。

```python
set1 = set('adcabde')
set2 = set('cdf')
print(set1)
print(set2)
print(set1 | set2)
print(set1.union(set2))
```

执行下面的代码，对集合进行交集操作。

```python
set1 = set('adcabde')
set2 = set('cdf')
print(set1)
print(set2)
print(set1 & set2)
print(set1.intersection(set2))
```

执行下面的代码，对集合进行差集操作。

```python
set1 = set('adcabde')
set2 = set('cdf')
print(set1)
print(set2)
print(set1 - set2)
print(set1.difference(set2))
```

执行下面的代码，对集合进行对称并集操作。

```python
set1 = set('adcabde')
set2 = set('cdf')
print(set1)
print(set2)
print(set1 ^ set2)
print(set1.symmetric_difference(set2))
```

执行下面的代码，对集合进行子集判断。

```python
set1 = set('adcabde')
set2 = set('cd')
print(set1)
print(set2)
print(set2 <= set1)
print(set2.issubset(set1))
```

执行下面的代码，为集合添加指定元素。

```python
set = {'Google', 'Facebook'}
set.add('TikTok')
print(set)
```

执行下面的代码，为集合批量添加多个元素。

```python
set = {'Google', 'Facebook'}
set.update({'TikTok', 'Microsoft'})
print(set)
```

执行下面的代码，删除并返回集合中的一个随机元素。

```python
set = {'Google', 'Facebook', 'TikTok'}
print(set.pop())
print(set)
```

执行下面的代码，删除集合中的指定元素，当元素不存在时会发生错误。

```python
set = {'Google', 'Facebook', 'TikTok'}
set.remove('TikTok')
print(set)
set.remove('TikTok')
```

执行下面的代码，删除集合中的指定元素。

```python
set = {'Google', 'Facebook', 'TikTok'}
set.discard('TikTok')
print(set)
set.discard('TikTok')
```

执行下面的代码，清空集合中所有元素。

```python
set = {'Google', 'Facebook', 'TikTok'}
set.clear()
print(set)
```
