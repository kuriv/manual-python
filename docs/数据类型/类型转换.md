# 类型转换

执行下面的代码，将对象的数据类型显示转换为所需的数据类型。

```python
print(6.66, type(6.66), int(6.66), type(int(6.66)))
print('233', type('233'), int('233'), type(int('233')))
print(233, type(233), float(233), type(float(233)))
print('6.66', type('6.66'), float('6.66'), type(float('6.66')))
print(233, type(233), str(233), type(str(233)))
print(2.33, type(2.33), str(2.33), type(str(2.33)))
```
