# 深浅拷贝

在 Python 中，对象赋值实际上是对象的引用。当创建一个对象，然后把它赋给另一个变量的时候， Python 并没有拷贝这个对象，而是拷贝了这个对象的引用。

```python
foo = [1, 2, 3, [4, 5, 6]]
bar = foo
print(foo, id(foo))
print(bar, id(bar))
foo.append(7)
print(foo, id(foo))
print(bar, id(bar))
```

执行下面的代码，对列表进行浅拷贝操作。注意，浅拷贝操作不会拷贝对象内部的子对象。

```python
import copy

foo = [1, 2, 3, [4, 5, 6]]
bar = copy.copy(foo)
print(foo, id(foo))
print(bar, id(bar))
foo.append(7)
print(foo, id(foo))
print(bar, id(bar))
foo[3].append(233)
print(foo, id(foo))
print(bar, id(bar))
```

为了使赋值操作时两个变量互不影响，可以进行深拷贝操作。

```python
import copy

foo = [1, 2, 3, [4, 5, 6]]
bar = copy.deepcopy(foo)
print(foo, id(foo))
print(bar, id(bar))
foo.append(7)
print(foo, id(foo))
print(bar, id(bar))
foo[3].append(233)
print(foo, id(foo))
print(bar, id(bar))
```
