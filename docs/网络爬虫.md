# 网络爬虫

在使用 Python 网络爬虫之前，请确保已安装 `requests` 包。

```
pip install requests
```

执行下面的代码，获取指定网页的 HTML 代码。

```python
import requests

url = 'https://www.google.com'
response = requests.get(url)
print(response.text)
print(response.content.decode())
```

执行下面的代码，获取指定网页的 HTML 代码，并保存到本地。

```python
import requests

url = 'https://www.google.com'
response = requests.get(url)
with open('google.html', 'wb') as file:
    file.write(response.content)
```

某些服务器为避免网络爬虫无休止的请求，会对 `user-agent` 进行校验。为尽量确保不被目标网站反爬虫系统识别并封锁 IP ，请确保已安装 `fake-useragent` 包。

```
pip install fake-useragent
```

执行下面的代码，模拟用户代理获取指定网页的 HTML 代码。

```python
from fake_useragent import UserAgent
import requests

url = 'https://www.google.com'
headers = {'User-Agent': UserAgent().random}
response = requests.get(url, headers=headers)
print(response.text)
print(response.content.decode())
```

执行下面的代码，构建请求参数。

```python
from fake_useragent import UserAgent
import requests

url = 'https://www.google.com/search?'
ua = UserAgent()
headers = {'User-Agent': UserAgent().random}
params = {'q': 'Python'}
response = requests.get(url, headers=headers, params=params)
print(response.text)
print(response.content.decode())
```
