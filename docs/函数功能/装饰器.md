# 装饰器

装饰器是 Python 中的高级功能，主要用来实现动态修改函数或类的行为。

```python
def deco(fn):
    print('foo')

    def wrap():
        print('bar')
        fn()
        print('baz')

    return wrap

@deco
def func():
    print('Hello World!')

func()
```

执行下面的代码，实现多个装饰器堆叠，注意此方式将按照从下到上包装、从上到下执行。

```python
def deco1(fn):
    print('foo')

    def wrap():
        print('bar')
        fn()

    return wrap

def deco2(fn):
    print('baz')

    def wrap():
        print('qux')
        fn()

    return wrap

@deco1
@deco2
def func():
    print('Hello World!')

func()
```
