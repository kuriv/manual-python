# 内置函数

执行下面的代码，查看所有内置函数。

```python
import builtins

print(dir(builtins))
```

执行下面的代码，对列表中所有元素进行求和计算。

```python
print(sum([1, 2, 3, 4, 5]))
```

执行下面的代码，返回列表中所有元素的最大值。

```python
print(max([1, 2, 3, 4, 5]))
```

执行下面的代码，返回列表中所有元素的最小值。

```python
print(min([1, 2, 3, 4, 5]))
```

执行下面的代码，将列表中对应的元素分别打包成元组，然后返回由这些元组组成的列表。

```python
print(list(zip([1, 2, 3], ['Google', 'Facebook', 'TikTok'])))
```

执行下面的代码，对序列中所有元素执行对应函数，并返回处理后的结果。

```python
print(list(map(lambda x: x ** 2, [1, 2, 3])))
```

执行下面的代码，过滤并保留函数返回的指定元素。

```python
print(list(filter(lambda x: x % 2, [1, 2, 3])))
```

执行下面的代码，对参数序列中的元素进行累积操作。

```python
from functools import reduce

print(reduce(lambda x, y: x + y, [1, 2, 3]))
```
