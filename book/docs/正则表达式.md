# 正则表达式

执行下面的代码，使用正则表达式匹配字符串。

```python
import re

res = re.match('He', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配单个任意字符，换行符除外。

```python
import re

res = re.match('.', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配单个任意数字。

```python
import re

res = re.match(r'\d', '233666123.456')
print(res)
print(res.group())
```

执行下面的代码，匹配单个任意非数字。

```python
import re

res = re.match(r'\D', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配单个任意空白字符，即空格符与缩进符。

```python
import re

res = re.match(r'\s', ' Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配单个任意非空白字符。

```python
import re

res = re.match(r'\S', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配单个任意字母。

```python
import re

res = re.match(r'\w', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配单个任意非字母。

```python
import re

res = re.match(r'\W', ' Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配列举的指定单个字符。

```python
import re

res = re.match('[He]', 'Hello World!')
print(res)
print(res.group())
res = re.match('[ll]', 'Hello World!')
print(res)
```

执行下面的代码，匹配列举的数字。

```python
import re

res = re.match('[0123456789]', '233666123.456')
print(res)
print(res.group())
res = re.match('[0-9]', '233666123.456')
print(res)
print(res.group())
```

执行下面的代码，匹配列举的字母。

```python
import re

res = re.match('[a-zA-Z]', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配非列举的字符。

```python
import re

res = re.match('[^a-zA-Z]', 'Hello World!')
print(res)
res = re.match('[^a-zA-Z]', '233666123.456')
print(res)
print(res.group())
```

执行下面的代码，匹配前一个字符出现 0 次或任意次。

```python
import re

res = re.match(r'\w*', 'Hello World!')
print(res)
print(res.group())
res = re.match(r'\w*', ' Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配前一个字符出现 1 次或任意次。

```python
import re

res = re.match(r'\w+', 'Hello World!')
print(res)
print(res.group())
res = re.match(r'\w+', ' Hello World!')
print(res)
```

执行下面的代码，匹配前一个字符出现 0 次或 1 次。

```python
import re

res = re.match(r'\w?', 'Hello World!')
print(res)
print(res.group())
res = re.match(r'\w?', ' Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配前一个字符出现指定次数。

```python
import re

res = re.match(r'\w{2}', 'Hello World!')
print(res)
print(res.group())
res = re.match(r'\w{5}', 'Hello World!')
print(res)
print(res.group())
res = re.match(r'\w{6}', 'Hello World!')
print(res)
res = re.match(r'\w{2,4}', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配开头或结尾。

```python
import re

res = re.match('^He', 'Hello World!')
print(res)
print(res.group())
res = re.match('.*$', 'Hello World!')
print(res)
print(res.group())
```

执行下面的代码，匹配指定分组。

```python
import re

res = re.match('(He)', 'Hello World!')
print(res)
print(res.group())
res = re.match('(he|He)', 'Hello World!')
print(res)
print(res.group())
```
