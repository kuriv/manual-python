# 迭代器

迭代器是可以记住当前遍历位置的对象，迭代器对象只能往前不能后退。

```python
list = [1, 2, 3, 4]
it = iter(list)
print(next(it))
print(next(it))
print(next(it))
print(next(it))
print(next(it))
```

迭代器对象可以使用常规循环语句进行遍历。

```python
list = [1, 2, 3, 4]
it1 = iter(list)
it2 = list.__iter__()
for i in it1:
    print(i)
while True:
    try:
        print(next(it2))
    except StopIteration:
        break;
```

执行下面的代码，创建自定义迭代器对象。

```python
class Iterator(object):
    def __iter__(self):
        self.num = 0
        return self

    def __next__(self):
        self.num += 1
        return self.num


it = iter(Iterator())
print(next(it))
print(next(it))
print(next(it))
print(next(it))
```
